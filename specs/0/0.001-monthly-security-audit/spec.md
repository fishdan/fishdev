# Monthly security audit

## Scope

Record a monthly dependency and installer security review for this Bash workflow repository. Identify dependency manifests, check installer syntax, and review external software acquisition. Record findings and validation in `.config/ai/progress.ai`.

## Acceptance criteria

- The audit date, commands, findings, and validation results are recorded.
- Critical or high severity vulnerabilities found in dependencies are fixed when safely possible.
- Findings outside the security remediation scope are identified for a later task.

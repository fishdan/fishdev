# Set up FishDev on Windows in VS Code

> **Note:** This guide has not yet been tested on native Windows. Commands were checked against official documentation and the SpecKit CLI on Linux only. Please report any problems.


These steps use the **PowerShell terminal in VS Code**. WSL and Git Bash are not required. Use a project folder that has not already been initialized with FishDev or SpecKit; the commands below add workflow files to that folder.

## 1. Prepare the project

Install [VS Code](https://code.visualstudio.com/download) and [Git for Windows](https://git-scm.com/download/win). Open your project folder with **File > Open Folder**, then open **Terminal > New Terminal**. If the terminal is not PowerShell, use **Terminal: Select Default Profile** from the Command Palette and choose PowerShell, then open a new terminal. VS Code documents [terminal setup](https://code.visualstudio.com/docs/terminal/getting-started) and [profile selection](https://code.visualstudio.com/docs/terminal/profiles).

Check that the terminal is in the project root and Git is available:

```powershell
Get-Location
git --version
git status --short
```

If this is a new folder and `git status` says it is not a repository, run `git init`. Commit or back up existing work before adding SpecKit to a project with files. Stop if this folder already contains `start.ai`, `.config/ai`, or `.specify`; this guide is for a first installation.

## 2. Install uv and SpecKit

FishDev pins the uv and SpecKit versions it was validated with. Each block below downloads one file, checks its SHA-256 digest against the value recorded for this FishDev release, and stops with an error before running anything that does not match.

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) with its versioned Windows installer. An existing uv 0.4.0 or newer is kept:

<!-- BEGIN fishdev-release:windows-uv (generated by .config/ai/tools/release.py update; do not edit) -->
```powershell
$ErrorActionPreference = 'Stop'
if (Get-Command uv -ErrorAction SilentlyContinue) {
    $found = [version]((uv --version).Split(' ')[1])
    if ($found -lt [version]'0.4.0') { throw "uv $found is older than 0.4.0. Run: uv self update 0.13.7" }
    Write-Host "Using existing uv $found"
} else {
    $uvInstaller = Join-Path ([System.IO.Path]::GetTempPath()) 'uv-installer-0.13.7.ps1'
    Invoke-WebRequest -UseBasicParsing 'https://github.com/astral-sh/uv/releases/download/0.13.7/uv-installer.ps1' -OutFile $uvInstaller
    $actual = (Get-FileHash -Algorithm SHA256 $uvInstaller).Hash.ToLowerInvariant()
    if ($actual -ne 'd9e70de578ea2653b631a5933c0296368fca4c91f412b46680661b81bbc399e0') { Remove-Item $uvInstaller; throw "uv installer digest mismatch: expected d9e70de578ea2653b631a5933c0296368fca4c91f412b46680661b81bbc399e0, got $actual" }
    powershell -ExecutionPolicy Bypass -File $uvInstaller
    Remove-Item $uvInstaller
}
```
<!-- END fishdev-release:windows-uv -->

Close the VS Code terminal and open a new one so its `PATH` includes `uv`. Then install Python 3.11 and the pinned [SpecKit package](https://github.github.io/spec-kit/installation.html) from its verified wheel:

<!-- BEGIN fishdev-release:windows-speckit (generated by .config/ai/tools/release.py update; do not edit) -->
```powershell
$ErrorActionPreference = 'Stop'
uv --version
uv python install 3.11
$wheel = Join-Path ([System.IO.Path]::GetTempPath()) 'specify_cli-1.3.3-py3-none-any.whl'
Invoke-WebRequest -UseBasicParsing 'https://files.pythonhosted.org/packages/2d/89/404e8e9aa5518a6ebb72a2f70f847b282807feaf94074d576ab5f947596a/specify_cli-1.3.3-py3-none-any.whl' -OutFile $wheel
$actual = (Get-FileHash -Algorithm SHA256 $wheel).Hash.ToLowerInvariant()
if ($actual -ne '661789638709a922bebb01cab2956c6be9730d487324ccdef9b4cb8ae8110c8b') { Remove-Item $wheel; throw "SpecKit wheel digest mismatch: expected 661789638709a922bebb01cab2956c6be9730d487324ccdef9b4cb8ae8110c8b, got $actual" }
uv tool install --force --python 3.11 $wheel
Remove-Item $wheel
specify version
```
<!-- END fishdev-release:windows-speckit -->

uv's PowerShell installer does not check the uv archive it downloads, so on Windows that step relies on HTTPS and the versioned release URL; the Linux and macOS installer checks it. uv checks the managed Python download itself. SpecKit requires Python 3.11 or newer. If `uv` or `specify` is not recognized after installation, reopen the terminal and check the relevant installer's `PATH` instructions.

## 3. Initialize SpecKit for PowerShell

Run this from the project root:

```powershell
specify init . --here --force --non-interactive --ignore-agent-tools --script ps --integration generic --integration-options="--commands-dir .config/ai/commands"
```

`--force` allows initialization in a folder that already has project files. `--script ps` installs PowerShell workflow scripts. The [generic integration](https://github.github.io/spec-kit/reference/integrations.html) places its commands under FishDev's vendor-neutral `.config/ai/` directory. `--ignore-agent-tools` skips checks for a particular AI agent executable; it does not install an agent.

## 4. Add FishDev's workflow files

Run the following in the same project root. The first block downloads every FishDev file to a temporary folder, checks each SHA-256 digest, and copies the files into the project only if all of them match. It does not execute the Linux installer.

<!-- BEGIN fishdev-release:windows-files (generated by .config/ai/tools/release.py update; do not edit) -->
```powershell
$ErrorActionPreference = 'Stop'
$fishDevSource = 'https://raw.githubusercontent.com/fishdan/fishdev/v0.5.0'
$fishDevFiles = [ordered]@{
    'start.ai' = 'f9cf8f94bf83ae558d5decbea4825ee331cc74722f281a16ae9fec4d41417c78'
    'fishdev-init.md' = '1203bf823ef1f03fb6aa3adbb14798dd7603520a232c30dfbb00bb2fc0ee3c0f'
    '.config/ai/defaults/constitution.md' = '3d95ca26524b2d281e553ced769a5a4c0dc710a81bb9bd4103942a3b9d940035'
    '.config/ai/defaults/verification.json' = 'acfcbd02dfd65dda1acf469b90201e6d6523d8a3aaf137bdcefa77510540dba3'
    '.config/ai/defaults/rules.json' = '7e6f2ce3182cea60a775e461f93ee4d103b68d8289d2f91cce7dd632789d2af6'
    '.config/ai/tools/fishdev.py' = '1f8e9016627a09a2485ebd05d78e17a7b8b3b98eeb9505c7054a0c8033f6cefa'
    'docs/verification-and-learning.md' = '5f134dc610987e9d48081af84f80b2ba2973e92f2985b4e6884162e6eb804394'
}
$stage = Join-Path ([System.IO.Path]::GetTempPath()) ('fishdev-' + [guid]::NewGuid())
try {
    foreach ($path in $fishDevFiles.Keys) {
        $staged = Join-Path $stage $path
        New-Item -ItemType Directory -Force -Path (Split-Path -Parent $staged) | Out-Null
        Invoke-WebRequest -UseBasicParsing "$fishDevSource/$path" -OutFile $staged
        $actual = (Get-FileHash -Algorithm SHA256 $staged).Hash.ToLowerInvariant()
        if ($actual -ne $fishDevFiles[$path]) { throw "Digest mismatch for ${path}: expected $($fishDevFiles[$path]), got $actual" }
    }
    foreach ($path in $fishDevFiles.Keys) {
        $parent = Split-Path -Parent $path
        if ($parent) { New-Item -ItemType Directory -Force -Path $parent | Out-Null }
        Copy-Item (Join-Path $stage $path) $path
    }
} finally {
    if (Test-Path $stage) { Remove-Item -Recurse -Force $stage }
}
```
<!-- END fishdev-release:windows-files -->

Then create the project's configuration and state files:

```powershell
Copy-Item .config/ai/defaults/verification.json .config/ai/verification.json
Copy-Item .config/ai/defaults/rules.json .config/ai/rules.json
$ignoreEntries = @('.config/ai/reports/', '.config/ai/local/', '.config/ai/learning/proposals.json', '__pycache__/')
if (-not (Test-Path .gitignore)) { New-Item -ItemType File .gitignore | Out-Null }
foreach ($entry in $ignoreEntries) {
    if (-not (Get-Content .gitignore | Where-Object { $_ -eq $entry })) {
        Add-Content -Path .gitignore -Value $entry
    }
}

Set-Content -Encoding ascii -Path AGENTS.md -Value 'Read and follow start.ai before doing any work.'
Copy-Item AGENTS.md CLAUDE.md
Copy-Item AGENTS.md GEMINI.md
Set-Content -Encoding ascii -Path .config/ai/repo.ai -Value '# Repository Settings'
Set-Content -Encoding ascii -Path .config/ai/progress.ai -Value '# Progress Log'
Set-Content -Encoding ascii -Path .config/ai/handoff.ai -Value '# Handoff'
Copy-Item .config/ai/defaults/constitution.md .specify/memory/constitution.md
```

The three `.ai` state files begin empty except for their headings. Keep future project settings, progress, and handoff notes in `.config/ai/`. The agent pointer files all direct assistants to `start.ai`.

Configure the new `.config/ai/verification.json` for your project's build, tests, browser surface, security checks, and performance budget. The starter profile deliberately fails unconfigured steps. Read the [verification and learning guide](verification-and-learning.md) for the JSON contract and examples.

## 5. Verify and begin

```powershell
specify version
Test-Path start.ai, .config/ai/progress.ai, .specify/memory/constitution.md, .specify/scripts/powershell
git status --short
```

Once the profile is configured, run `& (uv python find 3.11) .config/ai/tools/fishdev.py verify` from the project root. Run the equivalent Python command in CI after Python 3.11 is installed.

All four `Test-Path` results should be `True`. In your AI assistant's chat in VS Code, say: **“Follow the instructions in start.ai.”** Review the resulting changes, then commit the initialized workflow files with your project.

These instructions were checked against current official VS Code, uv, and SpecKit documentation, and the pinned SpecKit wheel was checked against FishDev's `init` options. The PowerShell commands have not been executed on a Windows machine in this repository's validation environment.
